# 🍭 Bonbon

> Простой редактор Lottie-анимаций в браузере. Один HTML-файл, без сборки, без фреймворков. PWA-friendly.

**Bonbon** — это минималистичный Lottie-редактор, написанный на Vanilla Web Components. Он умеет загружать, просматривать, редактировать и экспортировать Lottie JSON: работу со слоями, таймингом, трансформациями, keyframe-анимацией и кривыми Безье. Проект задуман как компактный, лёгкий и независимый инструмент, который можно открыть в браузере и сразу начать работать.

```
+---------------------------------------------------------------------+
|  Toolbar: [+ Слой] [Play] [Stop] [Импорт] [Экспорт] [Code View]     |
+---------------------+----------------------------+------------------+
|  Слои               |                            |  Свойства        |
|  ─ Red Circle       |      Превью-холст          |  ─ Transform     |
|  ─ Blue Square      |      (lottie-web)          |  ─ Keyframes     |
|  ─ Ellipse 3        |                            |  ─ Easing        |
+---------------------+----------------------------+------------------+
|  Таймлайн: линейка, playhead, полосы слоёв, keyframe-маркеры        |
+---------------------------------------------------------------------+
```

## Возможности

### Работа с проектом
- **Импорт** Lottie `.json` файлов.
- **Экспорт** текущего состояния в `.json`.
- **Code View** — редактирование JSON вручную с автовалидацией и debounce 500 мс.
- **PWA-ready**: единый HTML-файл, работает офлайн после загрузки.

### Слои
- Список слоёв с иконкой типа, именем и индексом.
- Выбор, переименование, дублирование, удаление.
- Изменение порядка **drag-n-drop** в сайдбаре и в строках таймлайна.
- Кнопки ↑/↓ в свойствах как альтернатива.

### Создание контента
- Прямоугольник, эллипс, текст.
- Выбор цвета заливки для фигур.
- Текстовые свойства: содержимое, размер, цвет.
- Трансформации: позиция X/Y, масштаб, поворот, прозрачность.

### Таймлайн
- Линейка с делениями по кадрам и секундам, вертикальная сетка.
- **Playhead** перетаскивается мышью, клик по линейке — перемотка.
- **Zoom** — кнопки `−`, `+`, `Fit`, а также `Ctrl+колесо` над таймлайном.
- **Горизонтальный скролл** — колесо над линейкой или `Shift+колесо`.
- **Вертикальная синхронизация** скролла между списком слоёв и строками таймлайна.
- Полосы слоёв с боковыми ручками для изменения `ip` / `op`.
- Сдвиг слоя целиком перетаскиванием полосы — меняет `ip`, `op`, `st`.
- Keyframe-маркеры на полосах.

### Анимация
- Кнопка **◆** в свойствах — поставить keyframe на текущем кадре.
- Keyframe-«чипы» под каждым свойством — быстрый переход к кадру и открытие Easing-редактора.
- **Easing-редактор** — интерактивная кривая Безье с двумя драг-хэндлами.
- **Bezier-пресеты**: Linear, Ease, Ease In, Ease Out, Ease In Out, Back In, Back Out, Expo Out.
- **Физические пресеты**: Bounce, Elastic, Back. Генерируют последовательность keyframes с реальной кривой, а не приближение через Безье.

### Воспроизведение
- Play / Pause / Stop.
- Плавный `requestAnimationFrame`-tick с учётом `fr` из JSON.
- Счётчик текущего и общего кадра.

## Стек

| Слой | Технология |
|------|-----------|
| Рендеринг анимации | [lottie-web](https://github.com/airbnb/lottie-web) (bodymovin) |
| UI-компоненты | Vanilla Web Components (`customElements.define`) |
| Стили | Чистый CSS, CSS Grid |
| Формат данных | Lottie JSON (Bodymovin) |
| Сборка | Не требуется — один HTML-файл |

**Почему без фреймворков.** Цель — максимальная автономность и минимальный вес. Один файл, открывается в любом современном браузере, легко встраивается и распространяется. Всё состояние — это один объект `lottieData`, всё общение между частями — через прямые вызовы и события.

## Как пользоваться

### Анимация круга

1. Выдели слой **Red Circle** в левом сайдбаре.
2. Поставь playhead на кадр 0 кликом по линейке.
3. В свойствах справа установи `Pos X = 100`.
4. Нажми **◆** рядом с `Pos X` — на таймлайне появится жёлтый маркер.
5. Перемотай на кадр 60.
6. Поменяй `Pos X = 400` — keyframe создастся автоматически.
7. Нажми **Play** — круг поедет вправо.

### Создание нового слоя

1. Кнопка **+ Слой** в тулбаре.
2. Выбери **Прямоугольник**, **Эллипс** или **Текст**.
3. Настрой свойства справа.

### Смена easing

1. Клик по keyframe-чипу **◆ 0** под нужным свойством.
2. Откроется редактор Безье.
3. Тяни жёлтые кружки или выбирай пресеты.
4. Для настоящей пружины — секция **«Физика»** (Bounce, Elastic, Back).

### Сдвиг слоя во времени

- **Середина полосы** — сдвиг всего слоя (`ip`, `op`, `st`).
- **Левый край** — только `ip`.
- **Правый край** — только `op`.

### Изменение порядка слоёв

- В сайдбаре: тащи элемент за любую точку.
- На таймлайне: тащи строку **не за полосу**, а за пустое место.
- Синяя линия показывает место вставки.

## Архитектура

Проект сознательно умещается в один файл, но внутри разделён на логические блоки:

```
1. DEMO_LOTTIE          — стартовая анимация
2. Утилиты              — deepClone, getPath, clamp, escapeHtml
3. Фабрики              — makeShapeLayer, makeTextLayer
4. Easing               — EASING_PRESETS, PHYSICS_EASINGS
5. LottieEditor         — корневой веб-компонент
   ├─ render()          — HTML-шаблон приложения
   ├─ cache()           — кэш ссылок на DOM
   ├─ attachEvents()    — подписки на события
   ├─ updatePreview()   — инициализация lottie-web
   ├─ renderLayers()    — левый сайдбар
   ├─ renderTimeline()  — таймлайн
   ├─ renderProps()     — правая панель свойств
   ├─ onPropInput()     — обработка полей ввода
   ├─ onPropClick()     — обработка кнопок, чипов, пресетов
   ├─ toggleKeyframe()  — создание/удаление keyframe
   ├─ startEasingDrag() — драг Безье-хэндлов
   └─ applyPhysics()    — генерация пружинных keyframes
```

### Поток данных

```
[lottieData] ──→ updatePreview() ──→ lottie-web
     │
     ├──→ renderLayers()
     ├──→ renderTimeline()
     ├──→ renderProps()
     └──→ refreshJsonIfVisible()
```

Все изменения (сдвиг слоя, keyframe, easing, drag-n-drop) идут через мутацию `this.lottieData` с последующим вызовом нужных рендер-функций.

## Ключевые понятия Lottie

| Поле | Значение |
|------|----------|
| `fr` | Frame rate (кадров в секунду) |
| `ip` / `op` | In Point / Out Point — окно видимости слоя или всей анимации |
| `st` | Start Time слоя |
| `ks` | Трансформация слоя (позиция, масштаб, поворот, прозрачность) |
| `layers` | Массив слоёв |
| `ty: 4` | Shape layer (фигура) |
| `ty: 5` | Text layer |
| `a: 1` | Свойство анимировано (массив keyframes) |
| `a: 0` | Свойство статично |
| `o` / `i` | Out / In easing у keyframe — контрольные точки Безье |

## Ограничения

- **Только базовые типы слоёв**: shape, solid, text. Precomp, image, audio не поддерживаются.
- **Маски, эффекты, выражения** — не поддерживаются.
- **Undo/Redo** — не реализовано.
- **Мультивыделение keyframes** — нет, только по одному.
- **Easing через физику** — генерирует статические keyframes. Параметры (частота Bounce, амплитуда Elastic) захардкожены.
- **PWA-обвязка** (manifest + Service Worker) — пока нет, работает как обычное веб-приложение.
- **Шрифты** — только системный Arial.
